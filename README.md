# Craft A Bot

An LLM & agent simulator styled as a 1970s/80s construction toy — see `CLAUDE.md` and `docs/design/` for the full design docs.

## Quickstart

```sh
npm install
npm run dev
```

Then open the printed local URL. `npm run demo` runs the same app with the mock provider preselected (no API key needed). See `docs/design/09-ROADMAP.md` for the current work package.
